# Changelog

All notable changes to **GradeVault** are documented here.

---

## [1.0.0] — 2026-10-18

### ✨ Added
- `add` and `view all` commands for student records, with labelled or positional marks
- Records saved to `gradevault.dat` and reloaded on the next run
- Class summary with pass / borderline / fail counts, weakest and strongest subject, trend against the last batch and a verdict
- `export` command that writes the roster and summary to a text file
- Colour-coded terminal output with ANSI escape codes
- Next.js project page
